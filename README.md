## About me

I'm an Odoo developer based in Lima, Peru. Through **[API SERVICE SAC](https://apiservicesac.com)** I build Odoo modules, integrations and the infrastructure they run on, and I turn the problems we solve for clients into products for the Odoo Community.

## Products

### 🚀 [Dooservice](https://dooservice.sh)

A platform to run Odoo on the server you choose: a VPS, a server created in your own cloud account, or a PC at the office.

- Connect a server with one line (Linux or Windows).
- Projects with Odoo 16 to 20, with production and development environments.
- Deploys from GitHub with `git push`, a backup before each deploy and one-click rollback.
- Daily backups, email alerts and custom domains.
- Servers on a private network published to the internet without opening router ports.
- Claude Code and OpenCode in development environments, with your own account.

👉 **[dooservice.sh](https://dooservice.sh)**

### 🖨️ [Dooprint](https://dooprint.apiservicesac.com)

Printing for Odoo Community on the receipt printers of a shop, a kitchen or a warehouse, even when Odoo runs in the cloud and nobody has a browser open.

| | |
|---|---|
| **Print service** | [apiservicesac/dooprint](https://github.com/apiservicesac/dooprint): runs on a computer next to the printers (Windows or Linux) |
| **Odoo modules** | [apiservicesac/dooprint-odoo](https://github.com/apiservicesac/dooprint-odoo): printing, Point of Sale and self order · AGPL-3 · one branch per version |
| **Odoo Apps** | [18.0](https://apps.odoo.com/apps/modules/18.0/dooprint) · [19.0](https://apps.odoo.com/apps/modules/19.0/dooprint) · [20.0](https://apps.odoo.com/apps/modules/20.0/dooprint) (free) |
